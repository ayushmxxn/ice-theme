# Ice Theme

A clean and modern theme pack for Visual Studio Code.

![Ice Theme Preview](./images/theme-preview.gif)

## Installation

Open the **Extensions** view (`Ctrl` + `Shift` + `X`).<br>
Search for **Ice Theme**.<br>
Click **Install**.<br>
Open **Preferences → Color Theme** (`Ctrl` + `K`, `Ctrl` + `T`).<br>
Select **Ice** or **Blaze**.
